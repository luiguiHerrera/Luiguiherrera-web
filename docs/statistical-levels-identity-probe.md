# Statistical Levels identity probe

`PROBE_IDENTITY` is a separate non-release operation in `.github/workflows/statistical-levels-release.yml` on `vercel-deployment`. It accepts only `probe_git_sha` and `probe_deployment_id`; the existing release inputs must be empty. No URL, role, project, service endpoint or Lambda name is accepted from the operator.

The probe accepts only the exact five-field fixture registered in `scripts/statistical-levels-release/probe-fixture.json`. That non-secret declaration is included in `source-manifest.json`, `SOURCE_SHA256SUMS`, and the workflow integrity pins. Input SHA and deployment ID must match before any metadata request; caller URLs and latest selectors are rejected. The probe still resolves the registered Preview using public GitHub metadata from the fixed Vercel integration, and the resolved origin must equal the registration. It selects the latest commit status for the supplied deployment ID, then requires the latest corresponding Preview deployment status to match the SHA, trusted creator, timestamp and exact origin links. A later Production deployment cannot replace the chosen Preview. No `deployments: read` permission or GitHub token is needed for these public reads.

Execution source and fixture source are separate checkouts. The workflow verifies its frozen helper hashes before running helpers, independently checks its GitHub execution identity and fixture ancestry, and verifies the fixture's pinned source files, 81 snapshots, provenance and 87-capability ledger. A probe records the fixture's authority as QA evidence; it never selects authority for publication. Trusted redirects may be manually followed at most twice, using the exact verified HTTPS Preview origin and an ordinary application path with no userinfo, port change, encoded/dot-segment path, query or fragment. Rejecting all query/fragment redirects is deliberately stricter than attempting to distinguish safe query values. Every trusted hop explicitly reissues the OIDC header. Cross-origin destinations are classified and never followed; loops and excess hops fail. This policy is local to the identity probe; shared release transports and ADOPT/PROMOTE jobs are unchanged.
