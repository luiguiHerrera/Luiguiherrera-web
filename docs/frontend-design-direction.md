# Frontend Design Direction

Current visual direction:
- Light/editorial interface.
- White or near-white background.
- Thin dividers instead of heavy cards.
- Less rounded UI.
- Minimal shadows.
- More whitespace.
- Sober typography and hierarchy.
- Dashboard previews as clean financial tables/charts.
- No generic fintech aesthetic.
- No dark SaaS dashboard look.

Inspired by:
- Premium editorial/product websites.
- Clean financial research interfaces.
- Jane Street / Apple style principles: clarity, restraint, spacing and hierarchy.

Important:
- No login in MVP.
- No user persistence.
- No external APIs yet.
- No cookies or analytics real implementation yet.
- Educational use only, not financial advice.
