# Sistema visual institucional

## Dirección visual

La web debe sentirse:

* sobria;
* premium;
* limpia;
* editorial;
* cercana;
* educativa;
* con rigor quant;
* moderna sin parecer fintech chillona;
* institucional sin parecer banco genérico.

Inspiraciones conceptuales:

* Citadel: fuerza institucional, portada fuerte, estructura seria.
* Jane Street: precisión, sobriedad técnica, limpieza, inteligencia visual.
* Apple: claridad, aire, jerarquía y reducción de ruido.

No copiar marcas, colores exactos, logos ni estilos propietarios.

## Color institucional

Color principal:
`#0B3436`

Nombre:
`Petróleo quant` o `Institutional teal`.

Significado:

* tecnología;
* datos;
* criterio;
* modernidad;
* prudencia;
* confianza.

## Paleta

```css
--color-institutional: #0B3436;
--color-ink: #111716;
--color-paper: #F7F4ED;
--color-soft: #EFEAE1;
--color-line: #D8D2C8;
--color-muted: #69706D;
--color-signal: #6F8F82;
--color-brass: #9A7A44;
--color-risk: #8A4E45;
```

## Uso recomendado

`--color-institutional`
Usar para:

* bloques hero puntuales;
* botones principales;
* estados activos;
* portada de PDF;
* acentos institucionales;
* navegación destacada con moderación.

No usar para:

* llenar toda la web de oscuro;
* fondos pesados en todas las secciones;
* señales de compra/venta.

`--color-ink`
Texto principal.

`--color-paper`
Fondo cálido general o secciones suaves.

`--color-soft`
Cards, paneles y fondos secundarios.

`--color-line`
Bordes finos y separadores.

`--color-muted`
Texto secundario.

`--color-signal`
Barras, lecturas positivas o progreso prudente.

`--color-brass`
Acento editorial puntual, nunca dominante.

`--color-risk`
Alertas prudentes, no rojo agresivo.

## Principios

1. Menos ruido, más intención.
2. Usar color para jerarquía, no decoración.
3. Mantener legibilidad retail.
4. Evitar estética de casino, trading agresivo o asesoría financiera.
5. No usar colores de semáforo infantiles.
6. No hacer todo oscuro: el blanco/cálido debe seguir respirando.
7. La web debe verse premium, pero amable.
