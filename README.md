# Luigui Herrera Web

Educational investment research lab built with Next.js and TypeScript.

The platform organizes tools for investor diagnostics, market regime analysis, statistical levels, quantitative portfolio research and red flag detection in investment proposals.

It is designed as an educational and research environment, not as personalized financial advice.

---

## Modules

* Investor diagnostic flow
* Market Regime Dashboard
* Statistical Levels Lab
* TD3 Portfolio Research Lab
* Investment Red Flags checklist
* Methodology and legal notes

---

## Tech stack

Next.js · TypeScript · Tailwind CSS · Vercel

---

## Status

Active personal research project.

The platform currently combines static research modules, mock/demo data and selected server-side data adapters where available.
